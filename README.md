# ЭМО — тренажёр

Тестовое задание «Web-программист»: тренажёр на чистых HTML, CSS и JS.
Вопросы (картинка и правильный ответ) лежат в `data/questions.json`.

## Запуск

Данные загружаются из JSON, поэтому нужен локальный сервер:

```
npx serve
```

Затем откройте адрес из консоли (обычно http://localhost:3000).
